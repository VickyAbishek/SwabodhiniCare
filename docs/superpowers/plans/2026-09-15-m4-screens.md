# M4: Screens Core — Implementation Plan

> **For agentic workers:** use superpowers:executing-plans. TDD for every JS module (Node's test runner; Web Crypto and `fetch` fakes). Screens are checked in a real browser against the local dev server.

**Goal:** Staff can open the app, do first-time setup, sign in, choose their own password, change language and light/dark in Settings, and sign out, against the real POC server code.

**Architecture:** Plain HTML pages in `public/`, each loading ES modules from `public/js/`. Screens talk to the server only through `public/js/api.js`, which loads the back-end adapter named in `config.js` with a dynamic `import()` (`backends/poc.js` now, `backends/prod.js` in Phase 1). Shared scripts (`shared/*.js`) are served at `/shared/`. The `[POC]` dev server runs the real Apps Script code in Node with the test fakes, so the whole POC works locally with no Google account.

**Spec:** main spec §10.1 (sign-in), §12 (UX, light/dark, language); POC spec §5, §7; scope map F1, F5–F8, F25, F27; mockups `docs/mockups/`.

## Global Constraints
- No frameworks, no npm runtime dependencies, no inline scripts or styles (strict CSP later). No `innerHTML` with data: `textContent` and DOM APIs only.
- Text 18 px+ (Tamil 19 px), tap targets ≥ 48 px, labels above fields, every icon has a text label.
- **Light is the default.** Dark is chosen in Settings, saved to the profile and cached in `localStorage` (`sc-theme`); the theme is applied by a small script in `<head>` before the page draws.
- The password never leaves the phone: PBKDF2-SHA256, 600,000 rounds, 16-byte salt, 256-bit key, as hex.
- All user-facing text comes from `public/i18n/en.json` / `ta.json` or `SC_Actions.ERRORS`.

## M4a: Browser core
| Task | Files | Tests |
|---|---|---|
| 1. Config + POC transport | `public/js/config.js`, `public/js/backends/poc.js` | posts `text/plain` JSON `{action, token, data}`; keeps the token in storage; network failure → `NETWORK_ERROR` envelope; bad JSON reply → `SERVER_ERROR` |
| 2. API client | `public/js/api.js` | loads the adapter named in config; `call()` returns envelopes; `NOT_SIGNED_IN` / `SESSION_EXPIRED` clear the token and notify the page |
| 3. Password key | `public/js/kdf.js` | PBKDF2 known-answer vector; 600k default; `newSalt()` 32 hex; password rules (8+ characters, not a common password) |
| 4. Language + theme | `public/js/i18n.js`, `public/i18n/en.json`, `ta.json`, `public/js/theme-boot.js`, `public/js/prefs.js` | `t()` with fallback to English and `{name}` values; every key exists in both files; theme/lang saved and applied |
| 5. Styles | `public/css/app.css` | tokens from the mockups (light first, dark under `[data-theme="dark"]`) |
| 6. Dev server | `poc/scripts/dev-server.mjs` | serves `public/` and `/shared/`; `POST /api` runs the POC server in memory; prints the setup code |
